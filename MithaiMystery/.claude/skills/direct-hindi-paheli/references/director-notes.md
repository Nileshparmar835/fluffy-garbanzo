# Director’s desk

## Two story shapes
A short challenge can hold one place, one rule and one question. The river reference shows exactly who is left alone when the farmer takes the boat. A viewer can reason with that image. Keep the question on screen while viewers decide.

An answer-and-challenge episode can earn attention twice. The sweet-shop reference rebuilds the previous transaction on a ledger and crosses out the note that came back. It celebrates the ₹500 answer, then switches to the night-time bike theft. Color, location and the type of evidence all change at the handoff. Use the two-part form only when the first answer is worth explaining.

## Editorial scale for a draft
Score each dimension 0, 1 or 2. Zero means missing. One means implied or difficult to see. Two means visible and specific. Treat a zero for fairness or payoff as a reason to revise. This is a writing tool.

| Dimension | Test for two points |
|---|---|
| First frame | Someone can name the object and the question after one glance. |
| Fairness | Every fact needed for the answer appears before the reveal. |
| Participation | Options are distinct and the viewer gets a quiet beat to commit. |
| Visual proof | The prop changes state or the diagram eliminates the other choices. |
| Payoff | The last line explains something the opening image could only suggest. |

## Scaling production
For a 30–45 second standalone episode, budget one set, a presenter, one reusable proof prop, three to ten labeled objects, and about eight to ten spoken cues. For a 75–95 second pair, budget a second set, a second question, an explicit handoff and two color palettes. Time the cut from recorded speech. The sample delivers 41.0 seconds across ten cues. These are planning ranges.

For a series, maintain one folder per episode. Keep shared fonts, narrator settings and export commands consistent. Record the episode question, correct answer, rule, shot that proves it, and whether the following episode owes a reveal. Track actual viewed-versus-swiped percentage, average percentage viewed and where the audience leaves. Compare different hooks on comparable episodes. Shorten a rule only if the remaining pictures still let a first-time viewer solve the puzzle.

## Transfer exercise
Brief: Three labeled tiffins contain only roti, only idli, or a mix; every label is wrong. Which box should you sample once? Show all three labels before the choice. The mixed label must conceal a single food. Draw that sample and use the two remaining wrong labels to place the other boxes. If the mixed-label box yields idli, it is the idli box. The roti-labeled box then holds the mix; the idli-labeled box holds roti. Use the mirror deduction if the sample is roti. Make a tiffin and label-swap sequence for this episode.
