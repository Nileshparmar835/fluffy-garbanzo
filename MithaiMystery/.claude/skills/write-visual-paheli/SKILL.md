# Write a visual Hindi puzzle

Start with the answer and its proof. In one sentence, state what the viewer must decide. Write the facts the viewer will know at decision time. Try each other answer against those facts. If another answer works, fix the premise before writing the hook.

Write three alternative opening lines and sketch one frame for each. Try a concrete wager, an odd visible detail and an invitation to choose. Say each aloud as if challenging a friend. Choose the hook whose promise can be shown immediately and proved by the final shot. Use the audience’s everyday Hindi. Numbers and deadlines must belong to the puzzle.

Write the beats in this order: hook, rule, first decision, visible consequence, second clue if needed, final guess, proof and callback. Combine beats when a short story needs fewer. Make each beat change what the viewer can infer. Let the audience commit before showing the correct option. Show why a plausible wrong answer fails. If the episode is standalone, pay off the hook within this episode.

Score the draft using references/script-scale.md. Show the three hook candidates, selected line, one reason tied to a shot, draft score and most valuable revision. Present the final script in Devanagari with short Roman Hindi screen text. Supply a verdict and proof separately.

## Map speech to pictures

For every beat, record exact spoken word or phrase, occurrence, object or person, onset action, completion action, what remains in frame, caption and optional sound. Choose recognizable artwork for every named clue. Make the noun establish the visual and the verb change its state. Introduce a named person on their name or have them visibly react if already in frame. When an object recurs, move it, reveal a detail or guide the gaze toward it. Keep the order and number of items consistent.

Example: “चंदा ने मिठाई का डिब्बा खोला।” Chanda enters on “चंदा”. A closed box slides into reach on “डिब्बा”. Its hinged lid rises on “खोला”. Show the viewer what is inside. One motif can span several connecting words. A floating label alone cannot demonstrate opening a box.

Use the selected female Mithai narrator, Voice A (Kokoro hf_beta, hi, 1.01×), in complete conversational takes. Deliver planned word anchors with the script. Set final seconds and frames only after the voice exists. For a rendered project, use the word timings and visual direction file to trigger both the picture and contact sound. Review the onset, contact and result of every key action. Play the decision beat muted to check it still reads.
